# 📊 PM-Data-Toolkit

> Kit d'outils méthodologiques, scripts d'analyse de données et automatismes dédiés à la Gestion de Projet SI et à la Conduite du Changement.

## 🎯 Objectif du projet
Ce dépôt regroupe une série de modules pratiques conçus pour faire le pont entre les besoins métiers et les aspects techniques (SQL, Python, structuration de données) dans un cadre de gestion de projet.

## 📂 Structure du dépôt
- `/SQL` : Requêtes de reporting, scripts de manipulation de bases de données relationnelles.
- `/scripts` : Mini-programmes utilitaires (nettoyage de données, automatisation de flux, logs).
- `/docs` : Documentation fonctionnelle, guides utilisateurs et modélisation de flux.
